# Artist Point LLC

A one-page static site for Artist Point LLC, a software company headquartered in Whatcom County, Washington.

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## GitHub Pages

1. Push this repository to GitHub.
2. In the repo settings, open **Pages**.
3. Set the source to the `main` branch and the `/` (root) folder.
4. Save. GitHub will publish the site at `https://<user>.github.io/<repo>/`.

The site uses relative paths, so it works as either a user site or a project site.
